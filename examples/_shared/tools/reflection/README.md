# Report and verification tools

Application `RegisteredTool` adapters for the [Reflection example](../../../patterns/reflection/README.md). `createDemo` creates a real CSV, optional initial draft and permission files. `ReflectionAdapters` registers loading, draft persistence, deterministic checks, review persistence and publication. Imports perform no work.

Sources and requests are bound by hashes. Net revenue is gross minus refunds; growth is rounded to two decimal places. Citations must match exact CSV rows. Immutable drafts, check proofs and reviews form the audit trail. Model review assesses supported interpretation and useful recommendations but cannot waive deterministic errors.

For another content, report or code task, replace domain contracts, source loaders and verifiers here. Keep business dependencies outside Core and never execute tools directly inside a Loop plan. The trusted application protects storage and supplies identity. See the [complete contracts](../../../../docs/worker-api/reflection-workflows.md).
